## 👋 About Me

안녕하세요. **Backend 개발과 DevOps, 클라우드 인프라**에 관심을 가지고 있는 개발자 박민정입니다.

Django, FastAPI, Spring 기반의 백엔드 개발을 중심으로 학습하고 있으며,  
Docker, Nginx, GitHub Actions, AWS, NHN Cloud를 활용한 배포 자동화와 운영 환경 구성에도 관심을 가지고 있습니다.

최근에는 대용량 DB 마이그레이션, Blue/Green 기반 무중단 배포, CI/CD 파이프라인 구축,  
Sentry · Grafana · Loki 기반 로깅 및 모니터링 환경 구성을 경험하며  
서비스가 안정적으로 배포되고 운영되는 구조를 고민하고 있습니다.
